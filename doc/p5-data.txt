`storeItem()`                                            |p5-data-storeItem|

Stores a value in local storage under the key name. Local storage is saved in
the browser and persists between browsing sessions and page reloads. The key
can be the name of the variable but doesn't have to be. To retrieve stored
items see getItem. Sensitive data such as passwords or personal information
should not be stored in local storage.

#### Returns:

    void

📂 *Sub-module: local_storage*

---
