INTRODUCTION                                    *p5-nvim-introduction*

p5.nvim is a Neovim plugin for creative coding with p5.js. It provides a
complete development environment for building interactive sketches directly
in Neovim.

Features:
- 💻 Live server with auto-reload for instant browser preview
- 📦 Package manager for p5.js contributor libraries
- 📺 Console to view browser logs in Neovim
- 📚 p5.js reference as built-in manpages
- 🗂️ Template projects with p5.js 2.x and 1.x
- 🔗 GitHub Gist integration for sharing sketches
- ✂️ 100+ p5.js code snippets (VS Code JSON format)

==============================================================================
REQUIREMENTS                                    *p5-nvim-requirements*

- Neovim 0.11.0 or later
- Python 3.7+ (for development server)
- websockets Python package (pip install websockets)
- curl (for console streaming and downloads)
- gh CLI (optional, for gist features)

==============================================================================
QUICK START                                      *p5-nvim-quick-start*

1. Install the plugin using your favourite package manager: >

   require("p5").setup({})

<
2. Create a new sketchspace: >

   :P5 create my-sketch

<
3. Start the live server: >

   :P5 server

<
4. Open http://localhost:8000 in your browser to see your sketch

COMMANDS                                            *p5-nvim-commands*

*P5*
   Main command. With no arguments, opens an interactive menu. With a
   subcommand, runs the specified operation.

:P5 menu
   Open the interactive menu. This is the default when running `:P5`
   without arguments.

:P5 create [name] [--1.x]
   Create a new sketchspace. If [name] is omitted, prompts for one.
   Pass --1.x to create a p5.js 1.x project instead of 2.x. >
   :P5 create my-sketch
   :P5 create
   :P5 create --1.x

:P5 setup
   Set up assets in the current sketchspace. Downloads gist files (if
   configured), creates a default sketch.js if missing, copies p5.js
   assets, generates libs.js, and installs configured libraries. >
   :P5 setup

:P5 install [library...]
   Install p5.js contributor libraries. Without arguments, shows a picker
   to select libraries. With arguments, installs specified libraries. >
   :P5 install ml5
   :P5 install ml5 p5play

:P5 uninstall [library...]
   Uninstall libraries. Without arguments, shows picker with installed
   libraries. With arguments, removes specified libraries. >
   :P5 uninstall ml5

:P5 server [port]
   Start or stop the development server (toggle). Default port is 8000. >
   :P5 server
   :P5 server 8080

:P5 docs
   Open the p5.nvim help file.

:P5 gist [description|sync|edit]
   Create, sync, or edit a GitHub Gist from your sketchspace. >
   :P5 gist "My awesome sketch"
   :P5 gist sync
   :P5 gist edit

:P5 update [library...]
   Update all installed libraries or specific ones. >
   :P5 update
   :P5 update ml5 p5play

:P5 skchbk [list]
   Clone all gists from a GitHub user into a local skchbk/ directory. >
   :P5 skchbk
   :P5 skchbk list

:P5 list
   Open a picker of recently used sketchspaces.

LIBRARY MANAGEMENT                          *p5-nvim-library-management*

p5.nvim includes 50+ contributor libraries for p5.js. Run `:P5 install`
to see all available libraries in a searchable picker.

Common libraries:
- ml5.js - Machine learning for the web
- p5.speech - Text-to-speech and speech recognition
- p5play - Game development with physics
- p5.party - Networked multiplayer sketches
- p5.xr - VR and AR sketches

CONFIGURATION                                    *p5-nvim-configuration*

Configure p5.nvim using the setup function: >

   require("p5").setup({
     server = {
       port = 8000,
       auto_start = false,
       auto_open_browser = true,
       live_reload = {
         enabled = true,
         port = 12002,
         debounce_ms = 300,
         watch_extensions = {".js", ".css", ".html", ".json"},
         exclude_dirs = {".git", "node_modules", "dist", "build"},
       },
     },
     console = {
       enabled = true,
       position = "below",
       height = 10,
     },
     libraries = {
       auto_update = false,
     },
     sketchbook = {
       user = "",
     },
   })

LUA API                                                *p5-nvim-lua-api*

require("p5").setup({config})                        *p5.setup()*
   Initialize the plugin with optional configuration.

require("p5.libraries").install_libs({names})       *p5.libraries.install_libs()*
   Install libraries by name.

require("p5.libraries").uninstall_libs({names})     *p5.libraries.uninstall_libs()*
   Uninstall libraries by name.

require("p5.libraries").get_available_libs()         *p5.libraries.get_available_libs()*
   Get list of all available contributor libraries.

require("p5.libraries").get_installed_libs()        *p5.libraries.get_installed_libs()*
   Get list of currently installed libraries in the project.

require("p5.server").start({port})                    *p5.server.start()*
   Start the live development server.

require("p5.server").stop_server()                   *p5.server.stop_server()*
   Stop the running server.

require("p5.cdp").open()                            *p5.cdp.open()*
   Open the CDP DevTools panel (or terminal fallback when Chrome not found).

require("p5.cdp").close()                            *p5.cdp.close()*
   Close the CDP panel or terminal console.

require("p5.cdp").toggle()                          *p5.cdp.toggle()*
   Toggle the CDP panel/terminal console visibility.

require("p5.project").create_project({name})        *p5.project.create_project()*
   Create a new p5.js project.

require("p5.gist").create({description})              *p5.gist.create()*
   Create a GitHub Gist from the current sketchspace.

require("p5.gist").sync()                             *p5.gist.sync()*
   Bidirectional sync with the associated gist.

require("p5.gist").edit()                             *p5.gist.edit()*
   Edit gist title or first comment.

KEYMAPPING                                          *p5-nvim-keymapping*

No keymaps are set by default. You can create your own: >

   vim.keymap.set("n", "<leader>p5", ":P5<CR>", { desc = "Open p5.nvim picker" })
   vim.keymap.set("n", "<leader>ps", ":P5 server<CR>", { desc = "Toggle server" })
   vim.keymap.set("n", "<leader>pc", ":P5 cdp<CR>", { desc = "Toggle CDP panel" })
   vim.keymap.set("n", "<leader>pg", ":P5 gist sync<CR>", { desc = "Sync gist" })

TROUBLESHOOTING                                  *p5-nvim-troubleshooting*

Q: Server won't start
A: Check that Python 3 and the websockets module are installed:
   pip install websockets
   Try a different port:
   :P5 server 8080

Q: CDP panel or terminal console shows no logs
A: Ensure the browser page is loaded and you've called console.log()
   in your sketch. The server must be running. Use :P5 cdp to open.

Q: Library installation fails
A: Check your internet connection. Ensure curl is installed.
   Verify you're in a valid sketchspace (has p5.json).

Q: Gist features don't work
A: Install and authenticate the GitHub CLI:
   gh auth login
